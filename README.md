# Sales Data Analysis Using MySQL

## Overview
This project focuses on analyzing retail sales data using MySQL. The analysis was performed on the Kaggle Sample Supermarket Dataset to identify sales trends, profit performance, customer demand, and regional business insights.

---

## Technologies Used
- MySQL
- SQL Queries
- Kaggle Dataset

---

## Key Features
- Sales Performance Analysis
- Profit Analysis
- Regional Analysis
- Customer Demand Analysis
- Category-wise Sales Analysis
- Subqueries & Advanced SQL Filtering

---

## SQL Concepts Used
- WHERE
- GROUP BY
- ORDER BY
- LIMIT
- HAVING
- Aggregate Functions
- Subqueries
- LIKE & Pattern Matching
